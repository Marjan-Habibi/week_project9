## 📌 About The Project
A responsive online store frontend where users can browse products, filter by category, and add items to cart. Designed for small businesses.

**Key Features:**
- Dynamic product listing with JavaScript
- Category filtering (e.g., electronics, clothing)
- Shopping cart with localStorage
- Fully responsive (Mobile + Desktop)

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox/Grid)
- Vanilla JavaScript (ES6)
- [Optional: Bootstrap/Tailwind if used]

## 🚀 Getting Started
1. Clone the repo:
   ```sh
   git clone https://github.com/Marjan-Habibi/week_project9.git
   ```
